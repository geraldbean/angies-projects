Autonomous Rover

Collecting samples on Mars

Project Overview

This project aimed to use the Robot Operating System (ROS) to navigate autonomously from a start point to a destination. The goal was to model a rover that could naviagte on the surface of Mars and collect samples left behind by Perserverance.

Autonomy, ROS, & Lidar


This rover auchieved autonomy predominantly using a lidar scan of the test environment which was used to generate a laser map that the rover could use to navigate from a starting point to anywhere else on the map.


Further Considerations


I had a few additional thoughts when conceptualizing this design which I thought would be important. One would be the orientation of the claw. I know that the cuurent Newton Sediment Sampler is oriented vertically. I think my design would work best if it were horizontal. As it acts like a sift I think that having it vertically oriented would leave room for unfiltered partiles to catch at the bottom.

Furthermore, I know that the current design uses rubber cups which I think could also work for my design. However, I have considered if maybe a denser kind of rubber that hold form better would be more effective for a sift like design.
